# Исправления системы упаковки десктоп-приложения - ЗАВЕРШЕНО

## 🎯 Проблемы, которые были устранены

### 1. ❌ Ярлык не ссылается на правильную папку
**Проблема:** Ярлык создавался без указания рабочей директории, поэтому БД создавалась рядом с ярлыком.

**Решение:** ✅ Исправлен `install.bat`:
- Добавлен параметр `WorkingDirectory` в PowerShell команды создания ярлыков
- Ярлыки теперь правильно указывают на папку приложения как рабочую директорию
- БД будет создаваться в папке приложения: `%PROGRAMFILES%\ConstructionTimeManagement\`

### 2. ❌ База данных создается не в той папке
**Проблема:** БД создавалась рядом с ярлыком вместо папки приложения.

**Решение:** ✅ Исправлен `main.py`:
- Добавлена установка рабочей директории при запуске приложения
- Для PyInstaller bundle используется `sys._MEIPASS`
- Для обычного запуска используется директория скрипта
- БД теперь всегда создается в правильном месте

### 3. ❌ Логин admin/admin не работает
**Проблема:** Пользователь admin не создавался автоматически при первом запуске.

**Решение:** ✅ Создана система автоматического создания пользователя admin:
- Создан модуль `src/data/initial_data.py` для инициализации данных
- Обновлен `database_manager.py` для вызова создания начальных данных
- Пользователь admin создается автоматически с паролем "admin"
- Создается соответствующая запись в таблице persons

$Shortcut.WorkingDirectory = '%PROGRAMFILES%\ConstructionTimeManagement';
