## Contributing to Documentation

When adding new documentation:
- Place it in the appropriate category folder
- Use clear, descriptive filenames
- Update this index if adding new categories
- Follow the established naming conventions

## File Naming Conventions

- Use `UPPER_CASE.md` for main documentation files
- Use `kebab-case.md` for specific topics
- Include version numbers in changelog files
- Use language prefixes for non-English documentation
