# Руководство пользователя по работе с конфликтами синхронизации

## 📋 Что такое конфликты синхронизации?

**Конфликт синхронизации** возникает, когда один и тот же документ или запись изменяется одновременно на разных рабочих местах. Например:

- Пользователь А изменил смету на своем компьютере
- Пользователь Б в то же время изменил ту же смету на другом компьютере
- При синхронизации система не может автоматически определить, какие изменения оставить

## 🔍 Как обнаружить конфликты?

### Индикаторы конфликтов

1. **В статус-баре** появляется значок ⚠️ рядом с индикатором синхронизации
2. **Всплывающее уведомление** в правом верхнем углу экрана
3. **Изменение цвета** индикатора синхронизации на оранжевый

### Типы уведомлений о конфликтах

#### 🟠 Предупреждение о конфликте
```
⚠️ Обнаружен конфликт синхронизации
Найдены конфликтующие изменения в документе "Смета №5".
Требуется ручное разрешение.
[Разрешить конфликт]
```

#### 📊 Множественные конфликты
```
⚠️ Обнаружено конфликтов: 3
Требуется ручное разрешение конфликтов синхронизации.
[Разрешить все]
```

## 🛠️ Как разрешить конфликты?

### Способ 1: Через индикатор статуса

1. **Нажмите** на значок ⚠️ в статус-баре
2. Откроется **диалог разрешения конфликтов**

### Способ 2: Через меню настроек

1. Откройте **"Настройки"** → **"Настройки синхронизации"**
2. Перейдите на вкладку **"Статус"**
3. Нажмите кнопку **"Разрешить конфликты"**

### Способ 3: Через уведомление

1. В всплывающем уведомлении нажмите **"Разрешить"**
2. Откроется диалог разрешения конфликтов

## ⚖️ Стратегии разрешения конфликтов

### 1. Использовать локальную версию

**Когда применять:**
- Вы уверены, что ваши изменения более актуальны
- Серверная версия содержит устаревшие данные
- Вы знаете, что другой пользователь работал со старой информацией

**Как применить:**
1. Выберите конфликт в списке
2. Нажмите **"Использовать локальную"**
3. Конфликт будет разрешен в пользу вашей версии

### 2. Использовать серверную версию

**Когда применять:**
- Серверная версия содержит более свежие данные
- Другой пользователь имел более полную информацию
- Вы сомневаетесь в правильности своих изменений

**Как применить:**
1. Выберите конфликт в списке
2. Нажмите **"Использовать серверную"**
3. Ваши изменения будут отменены в пользу серверной версии

### 3. Объединить изменения (ручное разрешение)

**Когда применять:**
- Обе версии содержат важные изменения
- Нужно сохранить части из обеих версий
- Требуется создать новую версию на основе обеих

**Как применить:**
1. Выберите конфликт в списке
2. Нажмите **"Объединить"**
3. Откроется форма редактирования
4. Внесите необходимые изменения
5. Сохраните результат

## 🔄 Массовые операции

### Разрешение всех конфликтов сразу

#### "Все → Локально"
- Разрешает **все** конфликты в пользу локальных версий
- Используйте, если уверены в правильности всех своих изменений

#### "Все → Сервер"
- Разрешает **все** конфликты в пользу серверных версий
- Используйте, если хотите получить все изменения с сервера

**⚠️ Внимание:** Массовые операции необратимы! Убедитесь в правильности выбора.

## 📝 Примеры разрешения конфликтов

### Пример 1: Конфликт в смете

**Ситуация:**
- Вы изменили название сметы с "Фундамент" на "Фундамент дома №1"
- Коллега изменил сумму сметы с 100,000 на 120,000 руб

**Сравнение версий:**
```
┌─────────────────────┬─────────────────────┐
│ Ваша версия         │ Серверная версия    │
├─────────────────────┼─────────────────────┤
│ Название: Фундамент │ Название: Фундамент │
│ дома №1             │                     │
│ Сумма: 100,000 руб  │ Сумма: 120,000 руб  │
│ Изменено: 14:30     │ Изменено: 14:25     │
└─────────────────────┴─────────────────────┘
```

**Рекомендуемое решение:** Объединить изменения
1. Нажмите **"Объединить"**
2. В форме редактирования установите:
   - Название: "Фундамент дома №1"
   - Сумма: 120,000 руб
3. Сохраните изменения

### Пример 2: Конфликт в ежедневном отчете

**Ситуация:**
- Вы добавили работника "Сидоров С.С." в отчет
- Прораб добавил другого работника "Козлов К.К." в тот же отчет

**Рекомендуемое решение:** Использовать серверную версию
1. Выберите конфликт в списке
2. Нажмите **"Использовать серверную"**
3. После разрешения добавьте своего работника заново

### Пример 3: Конфликт в табеле

**Ситуация:**
- Вы отметили работника как отсутствующего
- HR-менеджер отметил его как работающего с больничным

**Рекомендуемое решение:** Использовать серверную версию
- HR-менеджер имеет более точную информацию о статусе работника

## 🚨 Предотвращение конфликтов

### Лучшие практики

#### 1. Координация работы
- **Договоритесь** с коллегами о том, кто работает с каким документом
- **Используйте комментарии** для указания статуса работы над документом
- **Синхронизируйтесь чаще** - не реже чем каждые 30 минут

#### 2. Правильная организация работы
- **Завершайте работу** с документом перед переходом к другому
- **Сохраняйте изменения** регулярно
- **Не оставляйте** документы открытыми на длительное время

#### 3. Использование автосинхронизации
- **Включите автосинхронизацию** с интервалом 5-10 минут
- **Следите за статусом** синхронизации в статус-баре
- **Реагируйте** на уведомления о конфликтах немедленно

### Настройка стратегии по умолчанию

Вы можете настроить автоматическое разрешение простых конфликтов:

1. Откройте **"Настройки синхронизации"**
2. Перейдите на вкладку **"Дополнительно"**
3. Выберите стратегию разрешения конфликтов:
   - **Приоритет сервера** - автоматически использовать серверную версию
   - **Приоритет времени** - использовать более новую версию
   - **Ручное разрешение** - всегда спрашивать пользователя

## 🔧 Устранение проблем

### Конфликт не разрешается

**Возможные причины:**
- Нет соединения с сервером
- Документ заблокирован другим пользователем
- Ошибка в данных

**Решения:**
1. Проверьте соединение с сервером
2. Попробуйте разрешить конфликт позже
3. Обратитесь к администратору

### Слишком много конфликтов

**Возможные причины:**
- Несколько пользователей работают с одними документами
- Редкая синхронизация
- Проблемы с сетью

**Решения:**
1. Увеличьте частоту синхронизации
2. Координируйте работу с коллегами
3. Используйте массовые операции для разрешения

### Потеря данных после разрешения

**Что делать:**
1. **Не паникуйте** - система сохраняет историю изменений
2. Обратитесь к **администратору** для восстановления
3. В будущем **внимательнее** выбирайте стратегию разрешения

## 📊 Мониторинг конфликтов

### Статистика конфликтов

В настройках синхронизации (вкладка "Статус") вы можете увидеть:
- Общее количество конфликтов за период
- Типы конфликтующих документов
- Частоту возникновения конфликтов

### Отчеты о конфликтах

Администратор может предоставить отчеты о:
- Наиболее конфликтных документах
- Пользователях с частыми конфликтами
- Времени разрешения конфликтов

## ❓ Часто задаваемые вопросы

### В: Что произойдет, если я не разрешу конфликт?

**О:** Конфликт останется в системе и будет мешать синхронизации. Новые изменения в конфликтующем документе могут не передаваться на сервер.

### В: Можно ли отменить разрешение конфликта?

**О:** Нет, разрешение конфликта необратимо. Однако администратор может восстановить данные из резервной копии.

### В: Почему возникают конфликты, если я работаю один?

**О:** Конфликты могут возникать при работе с нескольких устройств (компьютер + ноутбук) или при проблемах с синхронизацией.

### В: Как узнать, кто создал конфликтующую версию?

**О:** В деталях конфликта указывается источник изменений (имя пользователя или код компьютера).

### В: Можно ли настроить автоматическое разрешение всех конфликтов?

**О:** Да, в настройках синхронизации можно выбрать стратегию "Приоритет сервера" или "Приоритет времени".

- Конфликты возникают слишком часто
- Не удается разрешить конфликт
- Потеряны важные данные
- Система работает нестабильно

### Куда обращаться

1. **Администратор системы** - для технических проблем
2. **Руководитель проекта** - для вопросов организации работы
3. **Техническая поддержка** - для критических проблем

### Информация для поддержки

При обращении за помощью укажите:
- Тип конфликтующего документа
- Время возникновения конфликта
- Действия, которые вы предпринимали
- Скриншот диалога конфликта (если возможно)
