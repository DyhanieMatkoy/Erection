# User Guide

Welcome to the user documentation for the CTM application. This section contains all the information you need to use the application effectively.

## Getting Started

If you're new to the application, start with the [Quick Start Guide](quick-start/).

## Main Features

- **[Daily Reports](features/daily-reports.md)** - Create and manage daily work reports
- **[Estimates](features/estimates.md)** - Work with cost estimates and calculations  
- **[Timesheets](features/timesheets.md)** - Manage employee timesheets and attendance
- **[Work Composition](features/work-composition.md)** - Handle work breakdown and composition
- **[Bulk Operations](features/bulk-operations.md)** - Perform bulk data operations
