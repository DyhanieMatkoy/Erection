# Интеграция синхронизации в пользовательский интерфейс

## Обзор

Система синхронизации полностью интегрирована в пользовательский интерфейс десктопного приложения, обеспечивая удобное управление синхронизацией и информирование пользователя о состоянии процесса.

## Компоненты интеграции

### 1. Индикатор статуса синхронизации

**Расположение:** Статус-бар главного окна (правая часть)

**Элементы:**
- **Цветной индикатор (●):** Показывает текущий статус
  - 🟢 Зеленый - синхронизация активна (онлайн)
  - 🔵 Синий - выполняется синхронизация
  - 🟠 Оранжевый - нет связи с сервером (офлайн)
  - ⚫ Серый - синхронизация не настроена
  - 🔴 Красный - ошибка синхронизации

- **Текст статуса:** Краткое описание состояния
- **Прогресс-бар:** Отображается во время синхронизации
- **Индикатор конфликтов (⚠):** Появляется при наличии неразрешенных конфликтов

**Интерактивность:**
- Клик по индикатору открывает диалог настроек синхронизации
- Клик по индикатору конфликтов открывает диалог разрешения конфликтов
- Всплывающие подсказки с дополнительной информацией

### 2. Диалог настроек синхронизации

**Открытие:** 
- Меню "Настройки" → "Настройки синхронизации"
- Клик по индикатору синхронизации в статус-баре

**Вкладки:**

#### Подключение
- **URL сервера:** Адрес сервера синхронизации
- **Код узла:** Уникальный идентификатор клиента
- **Токен аутентификации:** Автоматически получаемый токен
- **Кнопка "Зарегистрировать узел":** Регистрация на сервере
- **Кнопка "Проверить подключение":** Тест соединения

#### Расписание
- **Автоматическая синхронизация:** Включение/отключение
- **Интервал синхронизации:** От 1 до 1440 минут
- **Кнопка "Синхронизировать сейчас":** Ручной запуск
- **Прогресс-бар:** Отображение процесса синхронизации

#### Статус
- **Текущий статус:** Состояние подключения
- **Последняя синхронизация:** Время последней успешной синхронизации
- **Ожидающих изменений:** Количество несинхронизированных записей
- **Статистика:** Подробная информация о синхронизации

#### Дополнительно
- **Стратегия разрешения конфликтов:**
  - Приоритет сервера
  - Приоритет времени изменения
  - Ручное разрешение
- **Сохранять историю версий:** Включение/отключение
- **Сжатие данных:** Оптимизация трафика
- **Размер пакета:** Количество записей в одном пакете
- **Отладочное логирование:** Для диагностики проблем

### 3. Диалог разрешения конфликтов

**Открытие:**
- Клик по индикатору конфликтов (⚠)
- Автоматически при обнаружении конфликтов (опционально)

**Компоненты:**

#### Список конфликтов
- **Таблица конфликтов:** Тип объекта, время, источник, статус
- **Цветовая индикация:**
  - 🟡 Желтый - ожидает разрешения
  - 🟢 Зеленый - разрешен
  - 🔴 Красный - ошибка разрешения

#### Детали конфликта
- **Информация об объекте:** Тип, UUID, время конфликта
- **Сравнение версий:** Просмотр различных версий данных
- **Выбор разрешения:**
  - Использовать версию сервера
  - Использовать локальную версию
  - Объединить изменения
  - Пропустить (разрешить позже)

#### Массовые операции
- **"Все → Сервер":** Разрешить все конфликты в пользу сервера
- **"Все → Локально":** Разрешить все конфликты в пользу локальной версии

### 4. Система уведомлений

**Расположение:** Правый верхний угол главного окна

**Типы уведомлений:**

#### Информационные (синие)
- Начало синхронизации
- Успешное завершение синхронизации
- Восстановление соединения

#### Предупреждения (оранжевые)
- Синхронизация завершена с ошибками
- Обнаружены конфликты
- Потеря соединения с сервером

#### Ошибки (красные)
- Ошибка синхронизации
- Ошибка подключения к серверу
- Критические ошибки

#### Успех (зеленые)
- Успешная регистрация узла
- Успешное разрешение конфликтов

**Особенности:**
- **Автоматическое закрытие:** 5-10 секунд в зависимости от типа
- **Пауза при наведении:** Уведомление не закрывается при наведении мыши
- **Кнопки действий:** Быстрый доступ к настройкам или разрешению конфликтов
- **Ограничение количества:** Максимум 5 уведомлений одновременно

## Автоматическая инициализация

### Загрузка конфигурации

При запуске приложения автоматически:

1. **Читается файл `env.ini`** в разделе `[Sync]`
2. **Проверяется включена ли синхронизация** (`enabled = true`)
3. **Создается сервис синхронизации** с настройками из конфигурации
4. **Выполняется регистрация узла** (если токен отсутствует)
5. **Запускается автоматическая синхронизация** (если включена)

### Конфигурация по умолчанию

Если файл конфигурации отсутствует, создается с настройками по умолчанию:

```ini
[Sync]
enabled = false
server_url = http://localhost:8000
node_code = DESKTOP-CLIENT
auto_sync = true
sync_interval = 300
compression_enabled = true
conflict_resolution = server_wins
version_history = true
debug_logging = false
batch_size = 100
log_level = INFO
```

## Использование

### Первоначальная настройка

1. **Откройте настройки синхронизации:**
   - Меню "Настройки" → "Настройки синхронизации"
   - Или клик по индикатору синхронизации

2. **Настройте подключение:**
   - Введите URL сервера (например: `https://your-server.com`)
   - Введите уникальный код узла (например: `DESKTOP-OFFICE-1`)
   - Нажмите "Зарегистрировать узел"

3. **Настройте расписание:**
   - Включите автоматическую синхронизацию
   - Установите интервал (рекомендуется 5-10 минут)

4. **Сохраните настройки**

### Ежедневное использование

- **Мониторинг статуса:** Следите за индикатором в статус-баре
- **Ручная синхронизация:** При необходимости используйте кнопку "Синхронизировать сейчас"
- **Разрешение конфликтов:** Реагируйте на появление индикатора конфликтов
- **Чтение уведомлений:** Обращайте внимание на уведомления в правом углу

### Работа в автономном режиме

- Приложение полностью функционально без подключения к серверу
- Все изменения сохраняются локально
- При восстановлении соединения происходит автоматическая синхронизация
- Индикатор показывает статус "Офлайн" оранжевым цветом

## Устранение проблем

### Проблемы подключения

**Симптомы:**
- Красный индикатор статуса
- Уведомления об ошибках подключения
- Статус "Ошибка" в настройках

**Решения:**
1. Проверьте URL сервера
2. Убедитесь что сервер доступен
3. Проверьте интернет-соединение
4. Используйте кнопку "Проверить подключение"

### Проблемы аутентификации

**Симптомы:**
- Ошибки 401 в уведомлениях
- Невозможность синхронизации
- Пустой токен аутентификации

**Решения:**
1. Удалите токен в настройках
2. Нажмите "Зарегистрировать узел" заново
3. Проверьте уникальность кода узла

### Конфликты данных

**Симптомы:**
- Индикатор конфликтов (⚠) в статус-баре
- Уведомления о конфликтах
- Данные не синхронизируются

**Решения:**
1. Откройте диалог разрешения конфликтов
2. Просмотрите детали каждого конфликта
3. Выберите подходящую стратегию разрешения
4. Используйте массовые операции для множественных конфликтов

### Медленная синхронизация

**Симптомы:**
- Долгое выполнение синхронизации
- Таймауты подключения

**Решения:**
1. Увеличьте интервал синхронизации
2. Уменьшите размер пакета в дополнительных настройках
3. Включите сжатие данных
4. Проверьте скорость интернет-соединения

## Логирование и диагностика

### Включение отладочного режима

1. Откройте настройки синхронизации
2. Перейдите на вкладку "Дополнительно"
3. Включите "Отладочное логирование"
4. Установите уровень "DEBUG"
5. Сохраните настройки

### Просмотр логов

Логи синхронизации сохраняются в:
- **Windows:** `%PROGRAMFILES%\ConstructionTimeManagement\logs\sync.log`
- **Консоль приложения:** При запуске из командной строки

### Экспорт данных для поддержки

При обращении в техническую поддержку приложите:
1. Файл `env.ini` (без токенов)
2. Логи синхронизации
3. Скриншоты ошибок
4. Описание проблемы и шагов воспроизведения

## Безопасность

### Защита данных

- **Шифрование передачи:** Все данные передаются по HTTPS
- **Токены аутентификации:** Уникальные токены для каждого узла
- **Сжатие данных:** Минимизация объема передаваемых данных
- **Локальное хранение:** Данные остаются на устройстве при отсутствии соединения

### Рекомендации

1. **Используйте HTTPS** для production серверов
2. **Регулярно обновляйте** токены аутентификации
3. **Мониторьте** логи синхронизации на предмет подозрительной активности
4. **Ограничьте доступ** к файлу конфигурации
5. **Используйте уникальные коды узлов** для каждого клиента

## Заключение

Интеграция синхронизации в пользовательский интерфейс обеспечивает:

- **Прозрачность процесса** - пользователь всегда знает состояние синхронизации
- **Простоту настройки** - интуитивно понятные диалоги настроек
- **Автоматизацию** - минимальное вмешательство пользователя
- **Надежность** - автоматическое восстановление после сбоев
- **Информативность** - подробные уведомления и статистика

Система готова к использованию в production среде и обеспечивает бесшовную работу с синхронизацией данных между десктопными клиентами и сервером.
