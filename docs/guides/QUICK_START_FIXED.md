## Основные функции

### Работа со сметами

1. **Открыть список смет:**
   - Меню "Документы" → "Сметы"
   - Или нажмите кнопку "Сметы" на панели

2. **Создать новую смету:**
   - Нажмите "Создать" или Insert/F9
   - Заполните реквизиты
   - Добавьте строки работ
   - Нажмите "Сохранить" (Ctrl+S)

3. **Открыть существующую смету:**
   - Дважды кликните на смету в списке
   - Или выберите и нажмите Enter

4. **Импорт из Excel:**
   - Нажмите "Импорт из Excel"
   - Выберите файл
   - Смета создастся автоматически

### Работа с ежедневными отчетами

1. **Открыть список отчетов:**
   - Меню "Документы" → "Ежедневные отчеты"

2. **Создать отчет из сметы (способ 1):**
   - Откройте список смет
   - ПКМ на смете → "Создать Ежедневный отчет"
   - Отметьте нужные строки
   - Нажмите "Выбрать"

3. **Создать отчет из сметы (способ 2):**
   - Создайте новый отчет
   - Выберите смету
   - Нажмите "Заполнить из сметы"
   - Отметьте нужные строки
   - Нажмите "Выбрать"

4. **Сохранить отчет:**
   - Заполните фактические трудозатраты
   - Выберите исполнителей
   - Нажмите "Сохранить" (Ctrl+S)

## Горячие клавиши

### В списках
- **Insert / F9** - Создать новый документ
- **Enter** - Открыть выбранный документ
- **Ctrl+F** - Быстрый поиск
- **Delete** - Пометка на удаление

### В документах
- **Ctrl+S** - Сохранить
- **Ctrl+Shift+S** - Сохранить и закрыть
- **Ctrl+P** - Печать
- **Esc** - Закрыть

### В табличной части
- **Insert** - Добавить строку
- **Delete** - Удалить строку
- **F4** - Выбор из справочника
