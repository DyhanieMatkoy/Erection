# Импорт работ с многоуровневой иерархией

## Обзор

Система импорта работ из CSV поддерживает создание многоуровневой иерархии работ с автоматическим созданием групповых элементов. Это позволяет импортировать сложные структуры работ без ограничения по глубине иерархии.

## Формат CSV файла

### Базовый формат

```
Тип работ;Наименование работы;Цена;Единица измерения;Иерархия
```

### Поддерживаемые столбцы

- **Тип работ** (опционально) - Legacy столбец для обратной совместимости
- **Наименование работы** (обязательно) - Название работы или группы
- **Цена** (опционально) - Стоимость работ
- **Единица измерения** (опционально) - Автоматически создается в справочнике единиц
- **Иерархия** (рекомендуется) - Полный путь иерархии через разделитель

## Иерархическая структура

### Формат столбца "Иерархия"

Используйте разделитель ` > ` для указания пути иерархии:

```
Строительство > Общестроительные работы > Земляные работы
Строительство > Общестроительные работы > Фундаментные работы
Строительство > Отделочные работы > Штукатурные работы
Строительство > Отделочные работы > Малярные работы
```

### Альтернативные разделители

Система также поддерживает следующие разделители:
- ` | ` (вертикальная черта с пробелами)
- ` / ` (слэш с пробелами)
- `->` (стрелка)
- `|` (вертикальная черта)
- `/` (слэш)

### Приоритет столбцов

1. **Иерархия** (высший приоритет) - создает полную многоуровневую структуру
2. **Путь** (альтернативный формат иерархии)
3. **Тип работ** (legacy) - создает только один уровень подгруппы

## Примеры использования

### Пример 1: Простая иерархия

```
Тип работ;Наименование работы;Цена;Единица измерения;Иерархия
;;1500;м3;Строительство > Земляные работы > Разработка грунта
;;2800;м3;Строительство > Фундаментные работы > Бетонные работы
;;450;м2;Строительство > Отделочные работы > Штукатурка стен
```

### Пример 2: Legacy формат (обратная совместимость)

```
Тип работ;Наименование работы;Цена;Единица измерения;Иерархия
Земляные работы;Разработка котлована;1500;м3;
Земляные работы;Вывоз грунта;800;м3;
Фундаментные работы;Бетонирование;2800;м3;
```

### Пример 3: Смешанный формат

```
Тип работ;Наименование работы;Цена;Единица измерения;Иерархия
Отделочные работы;Покраска стен;320;м2;Строительство > Отделка > Покраска
;;Покраска потолков;350;м2;Строительство > Отделка > Покраска
Укладочные работы;Укладка плитки;1200;м2;Строительство > Отделка > Плитка
```

## Автоматическое создание справочников

### Единицы измерения

Система автоматически создает единицы измерения в справочнике `units`:
- Проверяет существование единицы с таким же названием
- Создает новую запись если единица не найдена
- Устанавливает корректную связь через `unit_id` в таблице `works`

### Групповые элементы

При импорте иерархии автоматически создаются групповые элементы:
- `is_group = 1` для групповых элементов
- `marked_for_deletion = 0` для всех новых элементов
- Правильные связи `parent_id` между уровнями иерархии

## Использование через API

### Эндпоинт импорта

```
POST /api/works/import-csv
```

### Параметры

- `file` - CSV файл для импорта
- `parent_id` (опционально) - Родительская группа для импорта
- `skip_existing` (опционально) - Пропускать существующие записи
- `delete_mode` (опционально) - Режим удаления по наименованиям

### Пример запроса

```javascript
const formData = new FormData();
formData.append('file', csvFile);
formData.append('parent_id', '123');
formData.append('skip_existing', 'true');

const response = await fetch('/api/works/import-csv', {
  method: 'POST',
  body: formData,
  headers: {
    'Authorization': 'Bearer ' + token
  }
});
```

## Командная строка

### Скрипт импорта

## Особенности и ограничения

### Ограничения
- Максимальный размер файла: 10MB
- Максимальное количество строк: 10,000
- Глубина иерархии: не ограничена
- Кодировка файла: UTF-8

### Особенности
- Автоматическое определение разделителей в иерархии
- Кэширование созданных групп и единиц измерения
- Транзакционная безопасность при импорте
- Поддержка отката изменений при ошибках

## Веб-интерфейс

### Кнопка быстрой загрузки примера

В интерфейсе работ доступна кнопка "Загрузить пример иерархии", которая:
- Создает пример CSV с многоуровневой структурой
- Автоматически открывает модальное окно импорта
- Предзаполняет все необходимые поля

### Модальное окно импорта

- Поддержка drag&drop для файлов
- Предпросмотр формата файла
- Настройки импорта (пропуск существующих, режим удаления)
- Отображение прогресса и результатов

1. Создать резервную копию базы данных
2. Тестировать импорт на небольшом наборе данных
3. Проверить результаты импорта в интерфейсе

## Поддержка и troubleshooting

### Частые проблемы

1. **Ошибка кодировки** - Используйте UTF-8 кодировку файла
2. **Неверный формат** - Проверьте разделители столбцов (должна быть точка с запятой)
3. **Пустые наименования** - Убедитесь что столбец "Наименование работы" заполнен
4. **Некорректные цены** - Используйте только цифры и разделитель точка

### Логирование ошибок

Система логирует все ошибки импорта с указанием:
- Номера строки в CSV файле
- Текста ошибки
- Частичного содержимого problematic строки

## Обновление существующих данных

При повторном импорте с опцией `skip_existing=false`:
- Обновляются цены и единицы измерения
- Сохраняется структура иерархии
- Не удаляются существующие связи
