# Инструкция: Печать смет с ресурсной ведомостью

## Что нового?

Теперь при печати сметы доступны два варианта:

1. **Стандартная смета** - обычный формат (как было раньше)
2. **Смета с ресурсной ведомостью** - смета + отдельная таблица с материалами

## Что такое ресурсная ведомость?

Это отдельная таблица, которая показывает все материалы, необходимые для выполнения работ по смете:

- Номер строки
- Код и название материала
- Общее количество
- Цена за единицу
- Общая стоимость
- Итоговая сумма по всем материалам

## Как использовать?

### Вариант 1: Через настройки (env.ini)

Откройте файл `env.ini` и добавьте или измените раздел:

```ini
[PrintForms]
format = EXCEL
estimate_variant = RESOURCE
```

Параметры:
- `format` - формат печати: `PDF` или `EXCEL`
- `estimate_variant` - вариант сметы: `STANDARD` или `RESOURCE`

После этого все сметы будут печататься в выбранном формате.

### Вариант 2: Программно

```python
from src.services.print_form_service import PrintFormService

service = PrintFormService()

# Установить вариант по умолчанию
service.set_estimate_print_variant('RESOURCE')

# Или указать при генерации
result = service.generate_estimate(estimate_id, 'RESOURCE')
```

## Форматы вывода

### PDF формат

- Первая страница: стандартная смета
- Вторая страница: ресурсная ведомость
- Удобно для печати на бумаге

### Excel формат

- Первый лист: "Смета"
- Второй лист: "Ресурсная ведомость"
- Удобно для дальнейшей обработки данных

## Важные замечания

1. **Материалы берутся из состава работ** - ресурсная ведомость формируется на основе материалов, привязанных к работам в смете

2. **Автоматический расчет количества** - система автоматически умножает норму расхода материала на количество работ

3. **Группировка материалов** - одинаковые материалы из разных работ суммируются

4. **Пустая ведомость** - если у работ нет привязанных материалов, ресурсная ведомость будет пустой

## Когда использовать каждый вариант?

### Стандартная смета (STANDARD)

Используйте когда:
- Нужна только общая информация о работах
- Детализация по материалам не требуется
- Документ для общего ознакомления

### Смета с ресурсной ведомостью (RESOURCE)

Используйте когда:
- Нужно планировать закупки материалов
- Требуется детальный анализ стоимости
- Необходим контроль расхода ресурсов
- Подготовка документации для заказчика

## Создание шаблонов

Для создания шаблонов Excel выполните:

```python
from src.services.print_form_service import PrintFormService

service = PrintFormService()
success, message = service.create_templates()
print(message)
```

Шаблоны будут созданы в папке `PrnForms/`.

## Примеры кода

### Генерация стандартной сметы

```python
from src.services.estimate_service import EstimateService

service = EstimateService()
result = service.generate_print_form(estimate_id, 'STANDARD')

if result:
    content, ext = result
    with open(f'смета.{ext}', 'wb') as f:
        f.write(content)
```

### Генерация сметы с ресурсами

```python
from src.services.estimate_service import EstimateService

service = EstimateService()
result = service.generate_print_form(estimate_id, 'RESOURCE')

if result:
    content, ext = result
    with open(f'смета_с_ресурсами.{ext}', 'wb') as f:
        f.write(content)
```

### Смена формата печати

```python
from src.services.print_form_service import PrintFormService

service = PrintFormService()

# Переключиться на PDF
service.set_print_format('PDF')

# Переключиться на Excel
service.set_print_format('EXCEL')
```

## Поддержка

При возникновении проблем проверьте:

1. Наличие материалов в базе данных
2. Привязку материалов к работам через таблицу `cost_item_materials`
3. Корректность данных в смете
4. Настройки в файле `env.ini`

## Заключение

Новая функциональность позволяет получать более детальную информацию о ресурсах, необходимых для выполнения работ по смете, что упрощает планирование и контроль проекта.
