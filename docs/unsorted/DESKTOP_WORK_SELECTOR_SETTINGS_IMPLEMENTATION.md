# Реализация настроек селектора работ для Desktop версии (PyQt6)

## Обзор

Реализована полная функциональность настройки селектора работ для desktop версии приложения на PyQt6, аналогичная web-версии. Пользователи могут выбирать между модальным и немодальным режимами открытия селектора работ, а также настраивать отображение иерархии и другие параметры.

## Реализованные компоненты

### 1. Диалог настроек (`src/views/dialogs/work_selector_settings_dialog.py`)

**Класс:** `WorkSelectorSettingsDialog`

**Возможности:**
- Выбор режима открытия (модальный/немодальный)
- Настройка режима отображения иерархии (плоский/дерево/пути)
- Управление видимостью элементов управления
- Автоматическое разворачивание групп
- Запоминание последней позиции
- Сброс к настройкам по умолчанию

**Интерфейс:**
```python
dialog = WorkSelectorSettingsDialog(parent, user_id)
if dialog.exec():
    settings = dialog.get_settings()
```

### 2. Улучшенный селектор работ (`src/views/dialogs/enhanced_work_selector_dialog.py`)

**Класс:** `EnhancedWorkSelectorDialog`

**Возможности:**
- Автоматическое применение пользовательских настроек
- Переключение между режимами иерархии в реальном времени
- Кнопка быстрого доступа к настройкам
- Индикатор текущего режима
- Поддержка модального и немодального режимов
- Детальная панель для режима "пути"
- Обработка ошибок базы данных

**Сигналы:**
```python
work_selected = pyqtSignal(int, str)  # work_id, work_name
```

**Использование:**
```python
dialog = EnhancedWorkSelectorDialog(parent, current_work_id, user_id)
dialog.work_selected.connect(on_work_selected)
dialog.exec()
```

### 3. Интеграция с формой сметы (`src/views/estimate_document_form.py`)

**Изменения:**

## Настройки пользователя

### Доступные опции:

1. **open_modal** (bool) - режим открытия:
   - `True` - модальное окно (блокирует основную форму)
   - `False` - немодальное окно (не блокирует работу)

2. **default_hierarchy_mode** (str) - режим отображения иерархии:
   - `'flat'` - плоский список (все работы в одном списке)
   - `'tree'` - иерархическое дерево (навигация по группам)
   - `'breadcrumb'` - с путями (показывать полный путь к работе)

3. **show_hierarchy_controls** (bool) - видимость элементов управления:
   - `True` - показывать кнопки навигации и переключения режимов
   - `False` - скрыть для упрощения интерфейса

4. **auto_expand_groups** (bool) - автоматическое разворачивание:
   - `True` - показывать содержимое групп при открытии
   - `False` - требовать ручного разворачивания

5. **remember_last_position** (bool) - запоминание позиции:
   - `True` - возвращаться к последней выбранной работе
   - `False` - всегда начинать с начала списка

### Сценарии использования:

#### Для опытных пользователей:
```python
expert_settings = {
    'open_modal': False,           # Немодальное окно
    'default_hierarchy_mode': 'flat',  # Все работы сразу
    'show_hierarchy_controls': True,    # Показывать управление
    'auto_expand_groups': False,        # Ручное управление
    'remember_last_position': True      # Запоминать позицию
}
```

#### Для новичков:
```python
beginner_settings = {
    'open_modal': True,                 # Модальное окно (фокус)
    'default_hierarchy_mode': 'tree',   # Пошаговая навигация
    'show_hierarchy_controls': True,     # Показывать подсказки
    'auto_expand_groups': True,          # Автоматическое разворачивание
    'remember_last_position': True       # Удобство использования
}
```

#### Для работы с большими списками:
```python
performance_settings = {
    'open_modal': True,                      # Фокус на выборе
    'default_hierarchy_mode': 'breadcrumb', # Полные пути
    'show_hierarchy_controls': False,        # Минимум элементов
    'auto_expand_groups': False,             # Экономия памяти
    'remember_last_position': True           # Быстрый доступ
}
```

### 1. Использование существующего сервиса настроек
