# Реализация печати смет с ресурсной ведомостью - Итоговый отчет

## Задача

Добавить второй вариант печатной формы для сметы с выводом отдельной таблицей ресурсной ведомости в формате: номер строки, материал, количество, цена, сумма. Внизу итого.

### 5. Структура ресурсной ведомости

**Формат таблицы**:
```
┌────────┬──────────────────────────────────┬─────────────┬──────────┬────────────┐
│ № п/п  │ Материал                         │ Количество  │ Цена     │ Сумма      │
├────────┼──────────────────────────────────┼─────────────┼──────────┼────────────┤
│ 1      │ 01.001 - Цемент М400             │ 2.500 т     │ 5000.00  │ 12500.00   │
│ 2      │ 02.015 - Арматура А500С          │ 150.000 кг  │ 45.00    │ 6750.00    │
└────────┴──────────────────────────────────┴─────────────┴──────────┴────────────┘
                                                            ИТОГО:     19250.00 руб.
```

**Алгоритм формирования**:
1. Получение всех работ из сметы (исключая группы)
2. Извлечение связанных материалов из `cost_item_materials`
3. Группировка по материалам
4. Расчет общего количества: `quantity_per_unit * estimate_line_quantity`
5. Расчет общей стоимости: `total_quantity * material_price`
6. Сортировка по коду материала

## Использование

### Программный интерфейс

```python
from src.services.estimate_service import EstimateService

service = EstimateService()

# Стандартная смета
result = service.generate_print_form(estimate_id, 'STANDARD')

# Смета с ресурсной ведомостью
result = service.generate_print_form(estimate_id, 'RESOURCE')
```

### Конфигурация

```python
from src.services.print_form_service import PrintFormService

service = PrintFormService()

# Установка варианта по умолчанию
service.set_estimate_print_variant('RESOURCE')

# Установка формата
service.set_print_format('EXCEL')
```
