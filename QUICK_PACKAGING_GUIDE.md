# Быстрое руководство по упаковке десктопного приложения

## Для разработчика

### 1. Упаковка приложения

```bash
# Запустите упаковку
package_desktop.bat

# Или вручную
python package_desktop.py
```

**Результат:**
- Папка `desktop_package/` с готовым приложением
- Архив `ConstructionTimeManagement_Desktop_v1.0.zip` (около 60 МБ)

### 2. Тестирование

```bash
# Быстрый тест упакованного приложения
test_packaged_app.bat
```

### 3. Передача клиенту

Передайте клиенту файл `ConstructionTimeManagement_Desktop_v1.0.zip`

## Для клиента

### Установка

1. **Распакуйте архив** в любую папку
2. **Запустите install.bat** от имени администратора
3. **Найдите ярлык** на рабочем столе

### Первый вход

- Логин: `admin`
- Пароль: `admin`
- **Обязательно смените пароль!**

### Удаление

Запустите `uninstall.bat` от имени администратора

## Структура пакета

```
ConstructionTimeManagement_Desktop_v1.0.zip
├── ConstructionTimeManagement/          # Приложение (~60 МБ)
│   ├── ConstructionTimeManagement.exe   # Исполняемый файл
│   └── _internal/                       # Библиотеки и ресурсы
├── install.bat                         # Установщик
├── uninstall.bat                       # Деинсталлятор
└── README.txt                          # Инструкция
```

## Системные требования

- Windows 10/11 или Windows Server 2016+
- 4 ГБ RAM
- 500 МБ свободного места
- Разрешение экрана 1024x768+

## Особенности

- **Автономное приложение** - не требует установки Python
- **Встроенная база данных** SQLite
- **Автоматическое резервное копирование** каждые 24 часа
- **Поддержка сети** - можно настроить общую базу данных

## Обновление

1. Создайте новый пакет: `package_desktop.bat`
2. Клиент удаляет старую версию: `uninstall.bat`
3. Клиент устанавливает новую: `install.bat`
4. База данных сохраняется автоматически

## Устранение проблем

### Приложение не запускается
- Запустите от имени администратора
- Проверьте антивирус (добавьте в исключения)
- Переустановите приложение

### Ошибка "Отсутствует DLL"
- Установите Visual C++ Redistributable 2015-2022
- Обновите Windows

### База данных не создается
- Проверьте права доступа к папке приложения
- Запустите от имени администратора

## Дополнительные возможности

### Сетевая работа

Для работы нескольких пользователей с общей базой:

1. Разместите базу данных на сервере
2. Отредактируйте `env.ini`:

```ini
[Database]
type = sqlite
path = \\server\shared\construction.db
```

### Подключение к серверной БД

Для PostgreSQL/MSSQL отредактируйте `env.ini`:

```ini
[Database]
type = postgresql
host = server.company.com
port = 5432
database = construction
username = user
password = password
```
