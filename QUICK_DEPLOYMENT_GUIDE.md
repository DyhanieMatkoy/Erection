# Быстрое развертывание десктоп-приложения

## 📦 Готовый пакет
**Файл:** `ConstructionTimeManagement_Desktop_FIXED_v1.0.zip` (~58 МБ)

## 🚀 Для клиента (3 простых шага)

### 1. Распаковать архив
Распакуйте `ConstructionTimeManagement_Desktop_FIXED_v1.0.zip` в любую папку.

### 2. Установить
Запустите `install.bat` **от имени администратора**.

### 3. Войти в систему
- Найдите ярлык на рабочем столе
- Логин: `admin`
- Пароль: `admin`

## 🔧 Если что-то пошло не так

### Проблема: Не получается войти в систему
**Решение:** Запустите `reset_admin_password.bat` от имени администратора.

### Проблема: Приложение не запускается
**Решение:** 
1. Запустите от имени администратора
2. Добавьте в исключения антивируса
3. Установите Visual C++ Redistributable

### Проблема: БД создается не там где нужно
**Решение:** Это исправлено в новой версии. Убедитесь что используете `ConstructionTimeManagement_Desktop_FIXED_v1.0.zip`.

## 📋 Системные требования
- Windows 10/11 или Windows Server 2016+
- 4 ГБ оперативной памяти
- 500 МБ свободного места на диске
- Права администратора для установки
