# Полное руководство по упаковке десктопного приложения

## 🎯 Обзор

Создана полная система упаковки десктопного приложения для развертывания у клиентов. Система включает:

- **Базовую упаковку** - простой и быстрый способ
- **Расширенную упаковку** - с дополнительными возможностями
- **Автоматическую установку** - для клиентов
- **Тестирование** - проверка работоспособности

## 📁 Созданные файлы

### Основные скрипты упаковки
- `package_desktop.py` - базовый скрипт упаковки
- `package_desktop.bat` - Windows batch для запуска
- `package_desktop_advanced.py` - расширенный скрипт с конфигурацией
- `test_packaged_app.bat` - тестирование упакованного приложения

### Документация
- `DESKTOP_DEPLOYMENT_GUIDE.md` - полное руководство по развертыванию
- `QUICK_PACKAGING_GUIDE.md` - краткое руководство
- `DESKTOP_PACKAGING_COMPLETE.md` - этот файл

### Ресурсы
- `fonts/` - папка для иконок и шрифтов приложения

## 🚀 Быстрый старт

### 1. Базовая упаковка (рекомендуется)

```bash
# Запуск упаковки
package_desktop.bat

# Или напрямую
python package_desktop.py
```

**Результат:**
- Папка `desktop_package/` с готовым приложением
- Архив `ConstructionTimeManagement_Desktop_v1.0.zip` (~60 МБ)

### 2. Расширенная упаковка

```bash
# С дополнительными опциями
python package_desktop_advanced.py --test --debug

# С пользовательской конфигурацией
python package_desktop_advanced.py --config my_config.ini
```

### 3. Тестирование

```bash
# Быстрый тест
test_packaged_app.bat

# Проверка работоспособности
.\desktop_package\ConstructionTimeManagement\ConstructionTimeManagement.exe
```

## 👥 Для клиента: Установка

### Системные требования
- Windows 10/11 или Windows Server 2016+
- 4 ГБ оперативной памяти
- 500 МБ свободного места на диске
- Разрешение экрана не менее 1024x768

### Процесс установки
1. **Распакуйте архив** в любую папку
2. **Запустите install.bat** от имени администратора
3. **Дождитесь завершения** установки
4. **Найдите ярлык** на рабочем столе

### Первый вход
- Логин: `admin`
- Пароль: `admin`
- **Обязательно смените пароль!**

## ⚙️ Конфигурация упаковки

### Базовые настройки (package_desktop.py)

Скрипт автоматически:
- Проверяет зависимости
- Создает PyInstaller spec файл
- Собирает standalone приложение
- Копирует ресурсы (база данных, шаблоны, шрифты)
- Создает установщик и деинсталлятор
- Упаковывает в ZIP архив

### Расширенные настройки (package_desktop_advanced.py)

Создайте файл конфигурации `packaging_config.ini`:

```ini
[app]
name = ConstructionTimeManagement
display_name = Система управления рабочим временем
version = 1.0.0
description = Система управления рабочим временем строительных бригад
author = Construction Management Team

[build]
console = false
debug = false
upx = true
onefile = false
exclude_modules = fastapi,uvicorn,pytest,numpy,pandas,matplotlib

[database]
include_sample = true
type = sqlite
path = construction.db

[output]
directory = desktop_package
create_installer = true
create_archive = true
archive_format = zip

[resources]
folders = PrnForms,fonts
files = env.ini
```

## 🔧 Дополнительные возможности

### Сетевая работа

Для работы нескольких пользователей с общей базой данных:

1. **Разместите базу на сервере:**
   ```
   \\server\shared\construction.db
   ```

2. **Отредактируйте env.ini на каждом компьютере:**
   ```ini
   [Database]
   type = sqlite
   path = \\server\shared\construction.db
   backup_enabled = true
   ```

### Подключение к серверной БД

Для PostgreSQL или MSSQL:

```ini
[Database]
type = postgresql
host = db-server.company.com
port = 5432
database = construction_prod
username = construction_user
password = secure_password
```

### Автоматическое обновление

1. **Создайте новую версию:**
   ```bash
   python package_desktop.py
   ```

2. **Передайте клиенту новый архив**

3. **Клиент обновляет:**
   - Запускает новый install.bat
   - Выбирает "Y" для обновления
   - База данных сохраняется автоматически

## 🛠️ Устранение проблем

### Проблемы упаковки

**PyInstaller не найден:**
```bash
pip install pyinstaller
```

**Отсутствуют зависимости:**
```bash
pip install -r requirements.txt
```

**Ошибка сборки:**
```bash
# Очистите кэш и пересоберите
python package_desktop.py
```

### Проблемы у клиента

**Приложение не запускается:**
- Запустите от имени администратора
- Проверьте антивирус (добавьте в исключения)
- Установите Visual C++ Redistributable

**Ошибка базы данных:**
- Проверьте права доступа к папке приложения
- Убедитесь что файл construction.db существует
- Восстановите из резервной копии

**Медленная работа:**
- Проверьте свободное место на диске (минимум 1 ГБ)
- Закройте другие приложения
- Перезагрузите компьютер

## 🔄 Синхронизация с сервером

### Возможности синхронизации

Десктопное приложение поддерживает **полную двустороннюю синхронизацию** с сервером:

- **Offline-first работа** - приложение работает без интернета
- **Автоматическая синхронизация** - каждые 5 минут (настраивается)
- **Разрешение конфликтов** - автоматическое и ручное
- **Безопасная передача** - HTTPS + токены аутентификации
- **Сжатие данных** - оптимизация трафика

### Настройка синхронизации

1. **Разверните сервер** согласно `deploy-to-prod/DEPLOYMENT_GUIDE.md`
2. **Упакуйте клиент** с поддержкой синхронизации (уже включена)
3. **Настройте в приложении:**
   - Меню "Настройки" → "Настройки синхронизации"
   - Server URL: `https://your-server.com`
   - Node Code: `DESKTOP-USER-1` (уникальный для каждого клиента)
   - Включить автоматическую синхронизацию

### Конфигурация env.ini

```ini
[Sync]
enabled = true
server_url = https://your-server.com
node_code = DESKTOP-USER-1
auto_sync = true
sync_interval = 300
compression_enabled = true
auth_token = 
last_sync = 
```

**Подробное руководство:** `DESKTOP_SYNC_SETUP_GUIDE.md`
