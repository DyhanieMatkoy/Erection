## 📋 Конфигурация по умолчанию

При первом запуске создается файл `env.ini` с настройками:

```ini
[Sync]
enabled = false                    # Отключено по умолчанию
server_url = http://localhost:8000 # Локальный сервер
node_code = DESKTOP-CLIENT         # Код узла по умолчанию
auto_sync = true                   # Автосинхронизация включена
sync_interval = 300                # 5 минут
compression_enabled = true         # Сжатие включено
conflict_resolution = server_wins  # Приоритет сервера
version_history = true             # История версий
debug_logging = false              # Отладка отключена
batch_size = 100                   # Размер пакета
log_level = INFO                   # Уровень логирования
```
