# Руководство по упаковке и развертыванию десктопного приложения

## Для разработчика: Упаковка приложения

### Быстрый старт

1. **Запустите упаковку:**
   ```bash
   package_desktop.bat
   ```

2. **Результат:**
   - Папка `desktop_package/` с готовым приложением
   - Архив `ConstructionTimeManagement_Desktop_v1.0.zip` для передачи клиенту

### Что происходит при упаковке

1. **Проверка зависимостей** - проверяется наличие всех необходимых библиотек
2. **Сборка исполняемого файла** - PyInstaller создает standalone .exe
3. **Подготовка ресурсов** - копируются шаблоны, шрифты, база данных
4. **Создание установщика** - генерируются install.bat и uninstall.bat
5. **Упаковка в архив** - все файлы упаковываются для передачи

### Структура готового пакета

```
ConstructionTimeManagement_Desktop_v1.0.zip
├── ConstructionTimeManagement/          # Основное приложение
│   ├── ConstructionTimeManagement.exe   # Исполняемый файл
│   ├── construction.db                  # База данных SQLite
│   ├── env.ini                         # Конфигурация
│   ├── PrnForms/                       # Шаблоны печати
│   ├── fonts/                          # Шрифты и иконки
│   └── _internal/                      # Библиотеки Python
├── install.bat                         # Установщик
├── uninstall.bat                       # Деинсталлятор
└── README.txt                          # Инструкция для клиента
```

## Для клиента: Установка приложения

### Системные требования

- **Операционная система:** Windows 10/11 или Windows Server 2016+
- **Оперативная память:** 4 ГБ
- **Свободное место:** 500 МБ
- **Разрешение экрана:** не менее 1024x768

### Установка

1. **Распакуйте архив** в любую папку
2. **Запустите install.bat** от имени администратора:
   - Правый клик на install.bat
   - "Запуск от имени администратора"
3. **Дождитесь завершения** установки
4. **Найдите ярлык** на рабочем столе или в меню Пуск

### Первый запуск

1. **Запустите приложение** через ярлык
2. **Войдите в систему:**
   - Логин: `admin`
   - Пароль: `admin`
3. **Обязательно смените пароль** администратора!

### Удаление

1. **Запустите uninstall.bat** от имени администратора
2. Приложение и все ярлыки будут удалены

## Настройка для работы в сети

### Если нужна работа с общей базой данных

1. **Остановите приложение** на всех компьютерах
2. **Отредактируйте файл** `%PROGRAMFILES%\ConstructionTimeManagement\env.ini`
3. **Измените секцию Database:**

```ini
[Database]
type = sqlite
path = \\server\shared\construction.db
backup_enabled = true
backup_interval_hours = 24
```

4. **Разместите базу данных** на сетевом диске
5. **Настройте права доступа** для всех пользователей

### Для работы с PostgreSQL/MSSQL

Если требуется подключение к серверной базе данных:

```ini
[Database]
type = postgresql
host = your-db-server
port = 5432
database = construction_prod
username = construction_user
password = your_password
```

## Обновление приложения

### Для разработчика

1. **Внесите изменения** в код
2. **Запустите упаковку** заново: `package_desktop.bat`
3. **Передайте новый архив** клиенту

### Для клиента

1. **Сделайте резервную копию** базы данных:
   - Скопируйте `%PROGRAMFILES%\ConstructionTimeManagement\construction.db`
2. **Удалите старую версию:** запустите uninstall.bat
3. **Установите новую версию:** запустите install.bat
4. **Восстановите базу данных** (если нужно)

## Резервное копирование

### Автоматическое

Приложение автоматически создает резервные копии каждые 24 часа в папке:
`%PROGRAMFILES%\ConstructionTimeManagement\backups\`

### Ручное

Скопируйте файл `construction.db` в безопасное место.

## Устранение неполадок

### Приложение не запускается

1. **Проверьте права доступа** - запустите от имени администратора
2. **Проверьте антивирус** - добавьте в исключения
3. **Переустановите** приложение

### Ошибка базы данных

1. **Проверьте файл** `construction.db` - он должен существовать
2. **Проверьте права доступа** к файлу базы данных
3. **Восстановите из резервной копии**

### Медленная работа

1. **Проверьте место на диске** - должно быть свободно минимум 1 ГБ
2. **Закройте другие приложения**
3. **Перезагрузите компьютер**

### Проблемы с печатью

1. **Проверьте папку** `PrnForms` - должны быть шаблоны Excel
2. **Установите Microsoft Office** или LibreOffice
3. **Проверьте принтер** - должен быть установлен и доступен

## Дополнительные возможности

### Настройка интерфейса

В файле `env.ini` можно изменить:

```ini
[UI]
theme = default          # Тема интерфейса
language = ru           # Язык (ru/en)
font_size = 10          # Размер шрифта
window_state_save = true # Сохранение состояния окон
```

### Настройка резервного копирования

```ini
[Database]
backup_enabled = true
backup_interval_hours = 24    # Интервал в часах
backup_keep_days = 30        # Сколько дней хранить копии
```

### Сетевые настройки

Для работы через интернет с API сервером:

```ini
[API]
enabled = true
base_url = https://your-server.com/api
timeout = 30
```

## FAQ

**Q: Можно ли установить на несколько компьютеров?**
A: Да, но для одновременной работы нужна общая база данных на сервере.

**Q: Работает ли без интернета?**
A: Да, приложение полностью автономное.

**Q: Можно ли импортировать данные из Excel?**
A: Да, есть функции импорта/экспорта.

**Q: Как добавить нового пользователя?**
A: Через меню "Администрирование" → "Пользователи".

**Q: Что делать если забыл пароль?**
A: Обратитесь к администратору для сброса пароля.
